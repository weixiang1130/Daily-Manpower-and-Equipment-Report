# 節點 27：匯出依工種展開分欄（v21）

## 背景

使用者（成控）以既有的計價 Excel 為例提出：明細與計價彙總匯出時，工種資訊
擠在同一欄文字裡（「粗工(2工/前2h:4h)、技術工(1工)」），但**不同工種計價費率
不同**，成本部計價需要每個工種自己成欄——目標格式為「粗工出工數／加班前2HR／
加班2HR後／技術工出工數量／…」逐工種三欄。

## 作法

新增 `laborTypeSplit(records)`：從篩選後的紀錄收集所有出現過的工種，
每工種展開三欄（出工數／加班前2h(時)／加班2h後(時)），追加在既有欄位之後。

- **兩個匯出都套用**：明細 CSV 逐單分欄；計價彙總 CSV 逐廠商合計分欄
- **欄序依該期間各工種總量降冪**——量大的工種（粗工/技術工）自然排前面
- **既有欄位原封不動**：分欄追加在尾端，已依賴舊欄位順序的下游流程不受影響
- **僅影響匯出檔**：畫面上的明細與彙總表維持原樣（動態欄會把畫面撐爆；
  匯出永遠全量，計價紅線 3）

## 口徑（與計價彙總、排名報表一致）

- 無工種列的單（v11 前舊制或直填總數）：以該單「工作內容類別」為欄名
- 加班歸段：有 `ot2Total` 用分段值；**僅有 `totalOT` 的舊單才整包歸前 2 小時**
  （v19.4 修正的同一句判斷式）
- 該單**有**此工種→數字照列（含 0）；**沒有**此工種→留空白——0 與空白在
  計價上意義不同（0＝回報過沒加班；空白＝該單根本沒叫這個工種）
- 待回報單：分欄處全空白（只有已回報單有工種數據）

## 驗證（本機注入示範資料、攔截下載實測 CSV 內容）

對照使用者附圖案例（某分包商 6/26 粗工1＋技術工1、加班皆 0）：

| 案例 | 明細分欄結果 |
|---|---|
| 附圖案例（一單兩工種、加班 0） | 兩工種各自成欄、0 照列 ✓ |
| 粗工含分段加班 | 3/4/2 ✓ |
| 無工種列但有分段加班 | 6/2/8（分段未被壓平）✓ |
| 舊制單僅 totalOT=4 | 3/4/0（全歸前2h）✓ |
| 待回報單 | 全空白 ✓ |

彙總驗算：各廠商分欄合計與明細逐單加總一致。欄序 打石(7.25)→粗工(4.75)→拆模(3.5)→
技術工(1) 降冪正確。既有欄位（前 26 欄／前 12 欄）位置與內容不變。
